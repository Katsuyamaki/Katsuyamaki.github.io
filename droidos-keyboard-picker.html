DroidOS Keyboard Picker

A lightweight Android utility from KatsuyaMaki LLC for choosing keyboards, including optional keyboard switching on supported Samsung foldable cover screens.

No ads No analytics No account Local operation

Features

  • Open Android's standard keyboard picker without elevated access.
  • Optional Samsung cover-screen keyboard switching using user-authorized Shizuku access.
  • No collection or transmission of typed text or other personal data.

Optional elevated access

Some Samsung cover-screen keyboard behavior is not available to ordinary applications through standard Android APIs. The optional cover-screen feature therefore uses Shizuku elevated access only after an in-app disclosure and explicit user authorization. Each switch is initiated by the user.
